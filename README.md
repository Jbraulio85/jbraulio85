## 👋 Sobre mí

Soy **desarrollador Full Stack** y **docente** en [Fundación Kinal](https://kinal.org.gt), enfocado en productos con impacto real — especialmente en **educación** y **EdTech**.

Trabajo el stack completo: desde **backend e infraestructura** hasta **interfaces modernas** y experiencia de usuario. Actualmente construyo **[shucode.lat](https://shucode.lat)** y exploro **IA aplicada a educación** (LLM, STT, TTS).

```text
🧠  Plataformas educativas con integración de IA
⚡  APIs REST escalables · Java · Spring Boot · Node.js
🖥️  Frontend moderno · React · Angular · TypeScript
📱  Apps multiplataforma · Flutter · React Native
🐳  Deploys con Docker · cloud y self-hosted
```
